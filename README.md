# Golden Hotels API Automation
## Project Summary: Performed Integration and API testing on Golden Hotels API. In here I have automated the CRUD functionalities for a user.

## Used Technologies
- Postman
- Newman
- nodejs



##How to run?

1. Clone this repository.
2. Install the dependencies:

   ```bash
   npm install
   ```
3. Add the `.env` file to the project root.
4. Run the tests:

   ```bash
   npm test
   ```
